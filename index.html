Sync

Stamped onto anything synced or saved as a backup file, so if this device and another ever disagree, you can tell whose copy is whose.
One code is the whole setup: get one here on the first device, type the same code into this box on the other, and both decks on every device stay in step. The code never leaves this device — it is turned into a lookup key and an encryption key here, and only those reach the sync server, which cannot read your data. Treat it like a password: anyone holding it can read and overwrite your copy. Both decks read this same field automatically.
