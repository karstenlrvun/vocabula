Sync

A Cloudflare Worker backs up both decks under one code — no GitHub account or token needed. Type the same code on every device; Latin and Greek each show their own push/pull status on their own Settings screen. The code is encrypted before it ever leaves this device (see js/sync.js), so this is the one place it's entered or shared.

Backup

One file holding both decks. Sync already keeps a copy on the server, but it is the same copy every device writes to — a file is the one that stays put. Saving is a tap because Safari silently blocks a download nothing asked for, so nothing here happens on its own.
