Backup & sync

Stamped onto anything pushed to the gist or saved as a backup file, so if this device and another ever disagree, you can tell whose copy is whose.
Set once, here. Both Latin and Λέξεις pick this up automatically — no need to enter it again in either one's own Settings, unless you've pinned them as two separate Home Screen icons rather than opening them from this page (see below), in which case each keeps its own copy as it always has. The token is never written into the gist or into a backup file — it stays in this browser's storage on this device. Anything on the device can still read it, so scope it to gists alone and revoke it if the phone goes astray.

Add this page to your Home Screen and open Latin and Λέξεις from the links above, rather than pinning each deck separately — that's what lets the backup fields above reach both of them. (Pinning them separately still works exactly as before; each just needs its own gist id and token typed in, the same as always.)
