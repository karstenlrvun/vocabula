One code is the whole setup: get one here on the first device, type the same code into the other, and both decks on every device stay in step — every save is pushed a few seconds later, and each launch fetches whatever the other device left and merges it in. Merging never loses a rating: both copies’ ratings are combined; a word rated on both since they last agreed keeps whichever side’s rating came later; an undone rating stays undone; each setting travels from whichever side changed it more recently (only this device’s name stays local). The code never leaves this device: it is turned into a lookup key and an encryption key here, and only the key and the encrypted copy ever reach the sync server, which cannot read them. Treat the code like a password — anyone holding it can read and overwrite your copy. Each copy of the app — Safari, a Home Screen icon, another device — labels its own ratings, so a merge can say where they came from. Opened through the launcher page, both fields are shared with the other deck automatically. Push now sends this device’s copy up as it is; Pull and merge fetches the synced copy and merges it in. The two Restore buttons are the safety net: the first puts back whatever this device last replaced (by a merge, a pull, a file restore, or a restore); the second fetches the sync server’s spare — the last copy pushed by a different copy of the app. A restored copy wins on every device: its word states and settings take over; no ratings are lost.

This app schedules with FSRS-6 — a published algorithm, implemented
          faithfully and never modified. Everything below is the layer around it. Each claim

Borrowed · stated first

          
The scheduling is not mine.

          
Twenty-one parameters, a learnable decay term, the standard power
            forgetting curve. It is implemented here exactly as specified and has never been
            altered — there is a tool in the repository whose only job is to lift this
            file’s scheduler out verbatim so it can be tested on its own.

          
Two more things worth conceding before anything is claimed:
            Anki has measured true retention natively since version 24.11, and it has
            logged per-review response time for far longer. Neither is new here.

Mine · and it only ever moves a grade down

          
A slow Easy is written down as Good.

          
The app times the gap between seeing a word and revealing it. It never
            shows a clock. One rule: take more than five seconds and an Easy is recorded as Good.
            Nothing is ever recorded higher than what was pressed, and Again is never touched.

          
The reasoning is narrow on purpose. “That was effortless”
            is the one claim a clock can check and no button can. Whether a pass was a
            struggle is a different question, and that one only the person can answer —
            which is what Hard is for.

          

            

              
              
            

            

          

        


        

          
Mine · the part I would actually defend

          
Four features were deleted on evidence, including two that had shipped that week.

          
For three weeks this app could not let a word go. Three settings, each
            defensible alone, combined into a scheduler where a mature word rated Good came back
            every ten minutes for ever — behind an escape hatch that, on a review card,
            could never fire. The settings text promised the escape hatch worked. Measured
            afterwards: 96% of real intervals had ended up set by an Easy press, and more
            than half of all ratings were the same words bouncing.

          
It survived code review, a passing test suite and three weeks of daily
            use. It took under a minute to find once somebody asked a degenerate question:
            what happens if you press the same button twelve times? That question is the
            control below.

Mine · the rule the whole app obeys

          
The app counts. You decide.

          
A word that keeps beating you can be suspended, and it comes back by
            resting — the pile is served longest-rested first, a few words a day, paid for out
            of the same allowance new words come from. Reaching the front of that queue does not
            release the word. It makes the app offer.

          
That shape is everywhere: the two exits appear on a struggling card and
            the app never takes either; nothing is ever released, rescheduled or graded on your
            behalf. An offer that fires on a word you know is not ready is an offer you learn
            to ignore.

          

            

              
              
            

            

          

          
Recovery is the half missing from the program this app takes its
            names from: its manual offers edit, delete or wait, and describes no way for a
            suspended card to earn its way back at all.
